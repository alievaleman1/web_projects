# Welcome to My Css Is Easy I
***

## Task
The goal of this project is to create a responsive web page using css Flexbox.the layout must change depending on the screen size: 
mobile view (less than 640px): Header, Hero, Content, Sidebar, Footer.
desktop view (greater than 640px): Header, Hero, Content and Sidebar side by side, Footer.

## Description
I solved this project by using Flexbox for the entire page layout.
The main container uses `display: flex` with `flex-direction: column`.
The `main` section uses Flexbox to place the Content and Sidebar next to each other.
A media query changes the layout for screens smaller than 640px by stacking the Content and Sidebar vertically.
Each section has its own background color and centered text.

## Installation
no installation is required
Clone or download the project files to your computer. Make sure that `index.html` and `style.css` are in the same directory. Then open `index.html` in your web browser to view the page.

## Usage
Open `index.html` in any modern web browser.

```
index.html
```
