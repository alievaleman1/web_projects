# Welcome to My Moving Box Realtime
***

## Task
The objective of this project is to create a smooth animation using JavaScript. The challenge is updating an element's position gradually while respecting the required movement speed and destination.

## Description
I implemented a real-time animation that moves a box diagonally across the screen. The position is updated at regular intervals until the box reaches the bottom-right corner of the viewport.

## Installation
No installation is required because the project consists of a single HTML file with embedded JavaScript. Open the file in a web browser to run the animation.

## Usage
Launch the index.html file in a browser and observe the box moving smoothly.
```
./my_project/ex00
```
